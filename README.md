# mplight66

Небольшой эксперимент по созданию кроссплатформенного музыкального плеера на python с использованием Flet и libmpv.

На текущем этапе реализован минимальный MVP:

* графический интерфейс на Flet;
* воспроизведение MP3;
* аудио-бэкенд на основе **libmpv** (`python-mpv`);
* простая функциональная архитектура без лишнего ООП.

## Запуск

```bash
make run
```

При первом запуске будут автоматически созданы виртуальное окружение и установлены зависимости.

Добавить самостоятельно трек в `assets/test.mp3`

## Структура проекта

